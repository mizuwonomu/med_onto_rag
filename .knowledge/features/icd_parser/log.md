# log.md (feature narrative, durable)

Built greenfield under TDD. Order: (1) `icd_hierarchy.py` static range table (map by numeric range, not first letter — a letter can span two chapters, e.g. D00-D48 ch. II vs D50-D89 ch. III); (2) `parse_code_stream` code-anchor parser; (3) EN/VI outer-join; (4) `find_column_split` histogram detector; (5) `extract_page_columns` crop + footer trim; (6) `build_record` assembly; (7) full-document orchestration. Real-PDF integration tests were used instead of mocks (real code, no mocks). During integration, three source-data problems surfaced and were investigated with ad-hoc measurement scripts: font glyph-drop (~434 codes, root-caused to Arial,Bold via PyMuPDF span-font inspection), column bleed (~345 codes / ~80 pages, root-caused to the widest-gap heuristic and fixed to nearest-center), and verbose descriptions (fixed via head/tail split). A word-level parser was spiked and quantitatively compared, then dropped for maintainability.

Result: produces **11,125** ICD candidate records. 0 duplicate codes, 0 codes with †/* remaining, 0 null `text`, 17 codes missing Vietnamese entirely (leading-letter font drop, fall back to English), 434 flagged `vi_glyph_ok=False` (Vietnamese kept in `text`), 2,431 with a separated `note_vi`. All chapter/block boundaries spot-checked (K21.0→XI/K20-K31, D48/D50 boundary, U07.1→XXII, etc.). 51 tests passing. Meets the definition-of-done (clean flat JSONL, bilingual, hierarchy-tagged, code-anchored).
